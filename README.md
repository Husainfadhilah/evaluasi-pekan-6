# Kedai Senja — Aplikasi Kasir dan Laporan Harian

## 1. Deskripsi Proyek

Kedai Senja adalah proyek sederhana untuk menghitung transaksi penjualan kedai, mengelola data menu, dan menampilkan laporan harian menggunakan JavaScript.

### Cara Menjalankan

1. Buka folder proyek di Visual Studio Code.
2. Buka file `index.html` di browser atau gunakan ekstensi Live Server.
3. Ikuti petunjuk pada halaman dan periksa hasil program melalui Console di browser jika diperlukan.

### Teknologi yang Digunakan

- HTML untuk struktur halaman web.
- JavaScript untuk logika kasir, perhitungan transaksi, dan laporan harian.
- Git untuk mengelola versi kode.
- GitHub untuk menyimpan kode dan bekerja menggunakan branch serta Pull Request.

## 3. Jawaban Pertanyaan

### A. Kenapa pekerjaan dibagi ke banyak branch, bukan semuanya di `main`?

Pekerjaan dibagi ke beberapa branch supaya setiap fitur atau perbaikan bisa dikerjakan secara terpisah. Dengan begitu, kode di `main` tetap lebih aman dan perubahan bisa diperiksa sebelum digabungkan.

### B. Apa fungsi `.gitignore` dan apa yang dimasukkan ke dalamnya?

File `.gitignore` digunakan untuk menentukan file atau folder yang tidak perlu dilacak dan dikirim ke Git. Isinya disesuaikan dengan proyek, misalnya file sementara, file sistem yang tidak diperlukan, atau file rahasia seperti `.env` jika digunakan.

### C. Apa beda merge lokal dengan Pull Request di GitHub?

Merge lokal dilakukan di komputer menggunakan Git untuk menggabungkan perubahan dari satu branch ke branch lain. Pull Request dibuat di GitHub agar perubahan bisa diperiksa dan didiskusikan terlebih dahulu sebelum digabungkan ke branch tujuan.
